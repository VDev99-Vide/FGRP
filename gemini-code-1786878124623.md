# dashboard.md — Đặc Tả Thiết Kế Giao Diện Analytics Dashboard (Dark Mode)

Tài liệu đặc tả chi tiết toàn bộ thành phần giao diện, thông số kỹ thuật, màu sắc, typography và bố cục được chuẩn hóa từ file thiết kế vector SVG gốc (kích thước chuẩn `1708px x 1859px`). Dùng tài liệu này làm đầu vào (prompt/spec) cho AI Agent lập trình giao diện (React, Vue, HTML/Tailwind CSS).

---

## 1. Hệ Thống Design Tokens

### 1.1. Bảng Màu (Color Palette)

| Phân Loại | Mã Hex | Tên / Vai Trò | Ứng Dụng Thực Tế |
| :--- | :--- | :--- | :--- |
| **Canvas Background** | `#081028` | Dark Navy Deep | Nền tổng thể toàn bộ trang (body/viewport) |
| **Card / Container BG** | `#0B1739` | Dark Blue Container | Nền các thẻ Card thống kê, khung Sidebar |
| **Table Row (Stripe)** | `#0A1330` | Midnight Blue Row | Nền các hàng chẵn/xen kẽ trong bảng dữ liệu |

| **Danger / High-Traffic**| `#DC2B2B` / `#FF5A65` | Coral Red | Điểm nút lưu lượng cao trên bản đồ thế giới |
| **Text Primary** | `#FFFFFF` | Pure White | Tiêu đề trang, số liệu chính, mã Order, text quan trọng |
| **Text Muted / Sub** | `#AEB9E1` | Slate Blue Light | Nhãn phụ, menu inactive, phần trăm, header bảng |
| **Border / Divider** | `#0B1739` | Subtle Border | Đường viền Sidebar, viền card, đường ngăn hàng (dày 0.6px) |

### 1.2. Bo Góc & Hiệu Ứng (Radius & Shadows)

* **Card Radius:** `12px` (`rounded-xl` hoặc `rounded-[12px]`)
* **Menu Item Radius:** `7px` (`rounded-[7px]`)
* **Progress Bar Radius:** `0.8px` - `2px` (bo nhẹ đầu thanh)
* **Badge / Tag / Checkbox:** `2px` (`rounded-[2px]`)
* **Hotspot Glow Effect:** Vòng tròn đồng tâm đa lớp (`opacity: 0.2`, `0.4`, `0.5`, `0.8`)
* **Font Family Khuyến Nghị:** `Inter`, `Plus Jakarta Sans`, hoặc `Roboto`

## 3. Đặc Tả Chi Tiết Từng Component

### 3.1. Sidebar Navigation (Thanh điều hướng bên trái)

* **Vị trí & Kích thước:** Cố định bên trái, chiều rộng `300px`, viền phải `0.6px solid #0B1739`.
* **Khối Thương Hiệu (Logo Unit):**
  * **Biểu tượng:** Khối hình cánh quạt/module bo góc kết hợp hai nửa màu: Nửa trái `#00C2FF`, nửa phải `#CB3CFF`.
  * **Text Brand:** `Dashboard` (Font Bold, Size 18px, màu `#FFFFFF`).
* **Danh sách Menu Navigation (Chiều cao mỗi item: `42px`, bo góc `7px`):**
  1. **Dashboard** *(Active Item)*:
     * Nền: `#081028` (hoặc background highlight nhẹ).
     * Icon: `Home` vector, màu tím `#CB3CFF`.
     * Text: `Dashboard`, màu tím `#CB3CFF`, font semi-bold.
  2. **Features**: Icon `Star` (Ngôi sao), màu `#AEB9E1`, Text `#AEB9E1`.
  3. **Users**: Icon `User` (Hình người), màu `#AEB9E1`, Text `#AEB9E1`.
  4. **Pricing**: Icon `Price Tag / Badge`, màu `#AEB9E1`, Text `#AEB9E1`.
  5. **Integrations**: Icon `Puzzle / Plug`, màu `#AEB9E1`, Text `#AEB9E1`.

---

### 3.2. Tiêu Đề Chính (Header Area)

* **Văn bản:** `Reports overview`
* **Style:** Size 24px - 28px, Font Bold, Màu `#FFFFFF`.
* **Vị trí:** Đặt đầu vùng nội dung chính.

---

### 3.3. Card: Users by Country & World Dot Map

* **Kích thước:** Rộng `1312px`, Cao `433px`, Bo góc `12px`, Nền `#0B1739`, Viền `0.6px solid #0B1739`.
* **Bố cục:** Chia làm 2 vùng chính ngăn cách bởi một đường kẻ dọc `0.6px stroke #0B1739`.

#### Phân khu 1: Thống Kê & Thanh Tiến Trình (Cột trái)
* **Tiêu đề khối:** `Users by Country` (Size 16px, Font Medium, màu `#FFFFFF`).
* **Khối chỉ số tổng:**
  * Giá trị lớn: `12.4k` (Size 32px, Font Bold, màu `#FFFFFF`).
  * Badge tăng trưởng kế bên:
    * Nền: `#05C168` với opacity `0.2`.
    * Viền: `0.6px solid #05C168` (opacity 0.2), bo góc `2px`.
    * Nội dung: Text `+28.5%` kèm icon mũi tên chếch lên `↗`, màu `#14CA74`.
* **Danh sách quốc gia & Progress Bar (Chiều cao thanh: `5px`, bo góc `0.8px`):**
  1. **United States**: `30%` (Thanh fill: `#CB3CFF`)
  2. **United Kingdom**: `20%` (Thanh fill: `#7E89AC`)
  3. **Canada**: `20%` (Thanh fill: `#9A91FB`)
  4. **Australia**: `15%` (Thanh fill: `#00C2FF`)
  5. **Spain**: `15%` (Thanh fill: `#D9E1FA`)

#### Phân khu 2: Bản Đồ Thế Giới Ma Trận Chấm (Cột phải)
* **Ma trận chấm (Dot Matrix Grid):**
  * Hàng trăm chấm tròn nhỏ đường kính `2px`, màu `#AEB9E1`, độ mờ `opacity: 0.4`, xếp thành hình các lục địa.
* **Các điểm nút phát sáng (Hotspots) — Cấu trúc 4 lớp đồng tâm:**
  * *Lớp 1 (Vòng ngoài):* Bán kính lớn, `opacity: 0.2`.
  * *Lớp 2 (Vòng giữa):* Bán kính vừa, `opacity: 0.4`.
  * *Lớp 3 (Lõi hào quang):* `fill: #0B1739`, `opacity: 0.5`.
  * *Lớp 4 (Tâm điểm):* Chấm tròn đặc (`rx="5.4px"`).
* **Vị trí & Màu sắc các điểm nóng:**
  * **Bắc Mỹ (Mỹ):** Cam `#FF9E2C` / `#FDB52A` kèm đường kẻ chỉ dẫn gập góc màu `#E8AD8C`.
  * **Châu Âu (UK/TBN) & Đông Á:** Đỏ san hô `#DC2B2B` / `#FF5A65`.
  * **Đông Nam Á & Úc:** Vàng hổ phách `#FDB52A`.

### 3.4. Card: Bảng Lịch Sử Giao Dịch (Recent Transactions Table)

* **Kích thước:** Rộng `628px`, Cao `452px`, Bo góc `12px`, Nền `#0B1739`, Viền `0.6px solid #0B1739`.
* **Cấu trúc hàng:**
  * Chiều cao mỗi hàng: `53.4px`.
  * Dòng xen kẽ (Zebra Stripe): Hàng chẵn `#0A1330`, hàng lẻ `#0B1739`.
  * Đường ngăn dòng: `0.6px solid #0B1739`.

#### Cấu trúc các cột dữ liệu:

| Cột | Quy Cách Hiển Thị | Ví Dụ Dữ Liệu |
| :--- | :--- | :--- |
| **Checkbox** | Ô vuông `11.4px`, bo góc `1.7px`. <br>• Checked: Nền `#CB3CFF`, icon check trắng.<br>• Unchecked: Nền `#0B1739`, viền `#7E89AC`. | `[✓]` hoặc `[ ]` |
| **Order ID** | Mã số đơn hàng, font Bold, màu `#FFFFFF`. | `#1532`, `#1531`, `#1530` |
| **Date & Time**| Ngày giờ, font Regular, màu `#AEB9E1` hoặc `#FFFFFF`. | `Dec 30, 10:00 AM` |
| **Status** | Bo góc `2px`, cao `18px`, kèm chấm tròn trạng thái `3px`: <br>• **Paid:** Nền `#05C168` (20%), Text `#14CA74`.<br>• **Pending:** Nền `#FFB016` (20%), Text `#FDB52A`. | `● Paid`<br>`● Pending` |
| **Amount** | Số tiền, font Semi-Bold, căn phải, màu `#FFFFFF` hoặc `#AEB9E1`. | `$324.40`, `$117.24` |

## 4. Hướng Dẫn Code Mẫu (Tailwind CSS & React)

Agent sử dụng mẫu JSX/Tailwind CSS dưới đây để dựng khung layout tổng thể:

```tsx
import React from 'react';
import { Home, Star, Users, Tag, Puzzle, ArrowUpRight, Check } from 'lucide-react';

export default function AnalyticsDashboard() {
  const countries = [
    { name: 'United States', percent: 30, color: 'bg-[#CB3CFF]' },
    { name: 'United Kingdom', percent: 20, color: 'bg-[#7E89AC]' },
    { name: 'Canada', percent: 20, color: 'bg-[#9A91FB]' },
    { name: 'Australia', percent: 15, color: 'bg-[#00C2FF]' },
    { name: 'Spain', percent: 15, color: 'bg-[#D9E1FA]' },
  ];

  const transactions = [
    { id: '#1532', date: 'Dec 30, 10:00 AM', status: 'Paid', amount: '$324.40', checked: true },
    { id: '#1531', date: 'Dec 29, 05:40 PM', status: 'Pending', amount: '$117.24', checked: false },
    { id: '#1530', date: 'Dec 29, 01:20 PM', status: 'Pending', amount: '$52.19', checked: false },
  ];

  return (
    <div className="flex min-h-screen bg-[#081028] text-white font-sans antialiased">
      {/* SIDEBAR */}
      <aside className="w-[300px] border-r border-[#0B1739] bg-[#0B1739]/40 p-6 flex flex-col gap-8 shrink-0">
        <div className="flex items-center gap-3">
          <div className="w-8 h-8 rounded-lg bg-gradient-to-br from-[#00C2FF] to-[#CB3CFF]" />
          <span className="text-xl font-bold tracking-wide">Dashboard</span>
        </div>

        <nav className="flex flex-col gap-2">
          <a href="#" className="flex items-center gap-3 px-4 py-3 rounded-[7px] bg-[#081028] text-[#CB3CFF] font-medium">
            <Home size={18}/>
            <span>Dashboard</span>
          </a>
          <a href="#" className="flex items-center gap-3 px-4 py-3 rounded-[7px] text-[#AEB9E1] hover:bg-[#0B1739] transition">
            <Star size={18}/>
            <span>Features</span>
          </a>
          <a href="#" className="flex items-center gap-3 px-4 py-3 rounded-[7px] text-[#AEB9E1] hover:bg-[#0B1739] transition">
            <Users size={18}/>
            <span>Users</span>
          </a>
          <a href="#" className="flex items-center gap-3 px-4 py-3 rounded-[7px] text-[#AEB9E1] hover:bg-[#0B1739] transition">
            <Tag size={18}/>
            <span>Pricing</span>
          </a>
          <a href="#" className="flex items-center gap-3 px-4 py-3 rounded-[7px] text-[#AEB9E1] hover:bg-[#0B1739] transition">
            <Puzzle size={18}/>
            <span>Integrations</span>
          </a>
        </nav>
      </aside>

      {/* MAIN CONTENT */}
      <main className="flex-1 p-10 flex flex-col gap-8 overflow-y-auto">
        <h1 className="text-2xl font-bold text-white tracking-tight">Reports overview</h1>

        {/* TOP SECTION: TRANSACTIONS TABLE */}
        <div className="grid grid-cols-1 xl:grid-cols-2 gap-6">
          <div className="bg-[#0B1739] rounded-[12px] border border-[#0B1739] p-6 shadow-xl">
            <div className="overflow-hidden rounded-[8px]">
              {transactions.map((tx, idx) => (
                <div 
                  key={tx.id} 
                  className={`flex items-center justify-between px-4 py-3.5 border-b border-[#0B1739] last:border-0 ${
                    idx % 2 === 0 ? 'bg-[#0A1330]' : 'bg-[#0B1739]'
                  }`}
                >
                  <div className="flex items-center gap-3">
                    <div className={`w-[14px] h-[14px] rounded-[2px] flex items-center justify-center border ${
                      tx.checked ? 'bg-[#CB3CFF] border-[#CB3CFF]' : 'border-[#7E89AC] bg-[#0B1739]'
                    }`}>
                      {tx.checked && <Check className="text-white stroke-[3]" size={10}/>}
                    </div>
                    <span className="font-bold text-white text-sm">{tx.id}</span>
                  </div>

                  <span className="text-xs text-[#AEB9E1]">{tx.date}</span>

                  <span className={`inline-flex items-center gap-1.5 px-2.5 py-0.5 rounded-[2px] text-xs border ${
                    tx.status === 'Paid'
                      ? 'bg-[#05C168]/20 border-[#05C168]/40 text-[#14CA74]'
                      : 'bg-[#FFB016]/20 border-[#FFB016]/40 text-[#FDB52A]'
                  }`}>
                    <span className={`w-1.5 h-1.5 rounded-full ${tx.status === 'Paid' ? 'bg-[#14CA74]' : 'bg-[#FDB52A]'}`} />
                    {tx.status}
                  </span>

                  <span className="font-semibold text-white text-sm">{tx.amount}</span>
                </div>
              ))}
            </div>
          </div>
        </div>

        {/* BOTTOM SECTION: USERS BY COUNTRY & DOT MAP */}
        <div className="bg-[#0B1739] rounded-[12px] border border-[#0B1739] p-8 grid grid-cols-1 lg:grid-cols-12 gap-8 shadow-xl">
          {/* Country list */}
          <div className="lg:col-span-5 flex flex-col gap-6">
            <div>
              <h2 className="text-white text-base font-medium">Users by Country</h2>
              <div className="flex items-center gap-3 mt-2">
                <span className="text-3xl font-bold text-white">12.4k</span>
                <span className="inline-flex items-center text-xs font-semibold text-[#14CA74] bg-[#05C168]/20 border border-[#05C168]/30 px-2 py-0.5 rounded-[2px]">
                  +28.5%
                  <ArrowUpRight className="ml-0.5" size={14}/>
                </span>
              </div>
            </div>

            <div className="flex flex-col gap-4">
              {countries.map((item) => (
                <div key={item.name} className="flex flex-col gap-1.5">
                  <div className="flex justify-between text-xs text-[#AEB9E1]">
                    <span>{item.name}</span>
                    <span>{item.percent}%</span>
                  </div>
                  <div className="w-full h-[5px] rounded-[1px] bg-[#081028] overflow-hidden">
                    <div className={`h-full ${item.color}`} style={{ width: `${item.percent * 2.5}%` }} />
                  </div>
                </div>
              ))}
            </div>
          </div>

          {/* Dot Map Container */}
          <div className="lg:col-span-7 border-t lg:border-t-0 lg:border-l border-[#0B1739] lg:pl-8 flex items-center justify-center min-h-[300px]">
            <div className="relative w-full h-full flex items-center justify-center">
              <span className="text-xs text-[#AEB9E1]/60">[World Dot Matrix Grid & Glow Hotspots Container]</span>
            </div>
          </div>
        </div>
      </main>
    </div>
  );
}
```
